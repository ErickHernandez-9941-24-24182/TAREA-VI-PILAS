ING EN SISTEMAS PLAN DOMINGO "SECCION:B"

Este programa simula el funcionamiento de deshacer y rehacer acciones en un editor simple.  
Utiliza dos pilas dinámicas implementadas con nodos, punteros y memoria dinámica new y delete.  
Permite realizar acciones, deshacer la última, rehacer acciones deshechas y mostrar el contenido de ambas pilas.  
Fue desarrollado en C++ para Visual Studio, aplicando estructuras dinámicas vistas en Programación.
